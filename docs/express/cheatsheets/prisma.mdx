| Raw pg | Prisma |
|---|---|
| `pool.query('SELECT * FROM todos')` | `prisma.todo.findMany()` |
| `WHERE id = $1` | `findUnique({ where: { id } })` |
| `INSERT ... RETURNING *` | `create({ data: {...} })` |
| `UPDATE ... RETURNING *` | `update({ where, data })` |
| `DELETE FROM ...` | `delete({ where: { id } })` |

```bash title="terminal"
npm install prisma --save-dev && npm install @prisma/client
npx prisma init
npx prisma migrate dev --name init
npx prisma generate
```

<Callout type="info" title="Remember">
  Only `models/` changes if you adopt this - routes and controllers stay the same, same lesson as Lesson 04.
</Callout>
