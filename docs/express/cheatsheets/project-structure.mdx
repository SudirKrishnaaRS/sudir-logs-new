| Layer | Job | React equivalent |
|---|---|---|
| `routes/` | Wiring only - URL+method → controller function | React Router config |
| `controllers/` | Actual logic - reads req, sends res | Logic in a custom hook |
| `models/` | The data + how to get/save it | A small API client module |

<FileTree>

- 📁 project-root/
  - 📄 index.js <FileNote>- assembles app, mounts routes</FileNote>
  - 📁 routes/
    - 📄 todos.js
  - 📁 controllers/
    - 📄 todoController.js
  - 📁 models/
    - 📄 todoModel.js

</FileTree>

```js
// index.js
app.use('/todos', require('./routes/todos'));

// routes/todos.js
router.get('/:id', todoController.getTodoById); // = GET /todos/:id

// controllers/todoController.js
function getTodoById(req, res) { /* logic, calls model */ }

// models/todoModel.js
module.exports = { getById: (id) => /* find + return data */ };
```

<Callout type="warn" title="One job per file">
  URL bug → check `routes/`. Logic bug → check `controllers/`. Bad data → check `models/`.
</Callout>
