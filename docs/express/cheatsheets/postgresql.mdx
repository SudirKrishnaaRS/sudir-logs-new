```bash title="terminal"
npm install pg dotenv
```

```bash title=".env"
# .env - never committed
DATABASE_URL=postgres://postgres:yourpassword@localhost:5432/tododb
```

```js
// index.js - top of file
require('dotenv').config();

// db/pool.js
const { Pool } = require('pg');
const pool = new Pool({ connectionString: process.env.DATABASE_URL });
module.exports = pool;
```

```sql
CREATE TABLE todos (
  id SERIAL PRIMARY KEY,
  title TEXT NOT NULL,
  completed BOOLEAN DEFAULT false
);
```

<Callout type="warn" title="Always remember">
  `.env` goes in `.gitignore` before your first commit. `pool.query()` returns a Promise - it's async.
</Callout>
