## Validate before you use req.body

```js
function createTodo(req, res) {
  const { title } = req.body;
  if (!title) return res.status(400).json({ error: 'title is required' });

  const newTodo = todoModel.create({ title });
  res.status(201).json(newTodo);
}
```

<Callout type="warn" title="Always remember">
  `req.body` only exists because of `app.use(express.json())`. A client can send anything -
  or nothing - check before you use it.
</Callout>

## Full model shape (in-memory)

```js
module.exports = {
  getAll: () => todos,
  getById: (id) => todos.find(t => t.id === Number(id)),
  create: (data) => { /* push + return new todo */ },
  update: (id, data) => { /* find, mutate, return or null */ },
  remove: (id) => { /* splice, return true/false */ },
};
```
