| Term | What it means |
|---|---|
| Call stack | Where your synchronous JS actually executes, one frame at a time |
| libuv | C library that runs slow work (files, network, timers, DB) off the JS thread |
| Callback queue | Holds finished async callbacks until the call stack is empty |
| Event loop | Continuously checks "is the stack empty?" then runs the next queued callback |

<Callout type="warn" title="Core rule">
  A callback (even a 0ms `setTimeout`) never runs until the call stack is completely empty. Synchronous code always finishes first.
</Callout>

```js
console.log('first');
setTimeout(() => console.log('third'), 0);
console.log('second');
// Always: first, second, third
```
